# README – Power BI Assignment

## Project Title

**Power BI Assignment – Data Transformation and Data Modeling**

## Project Description

This project was created using **Microsoft Power BI** to perform data transformation, cleaning, modeling, and analysis of sales-related data.

The project involves importing multiple datasets, transforming the data using Power Query, creating relationships between tables, and developing a data model for analysis and reporting.

## Files Used

The project includes the following datasets:

* **List of Orders**
* **Order Details**
* **Sales Target**

## Tools Used

* Microsoft Power BI Desktop
* Power Query
* Data Modeling
* DAX (where required)

## Key Tasks Performed

### 1. Data Import

Imported the required datasets into Power BI.

### 2. Data Cleaning and Transformation

Performed necessary data-cleaning operations using Power Query, including:

* Checking data types
* Removing errors and unnecessary values
* Handling missing or null values
* Renaming columns where necessary
* Preparing data for analysis

### 3. Data Modeling

Created relationships between the relevant tables to build an efficient data model.

### 4. Data Analysis

Analyzed the available sales and order data to understand:

* Sales performance
* Order details
* Category-wise performance
* Target versus actual performance


This project was developed as part of a learning assignment to gain practical experience in **Power BI data transformation and data modeling**.
